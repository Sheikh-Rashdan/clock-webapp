# Clock Webapp
A React-powered clock web app featuring a customizable 12/24-hour live clock, stopwatch with pause and multiple lap tracking, and multi-alarm support, with all preferences and data persistently stored in localStorage.

## Description
This React-based clock web application is designed to provide a complete time management experience through three core sections: Clock, Stopwatch, and Alarm. The app features a modern and responsive interface that makes it simple for users to switch between functionalities while maintaining smooth performance and usability across devices. Built entirely with React, the application focuses on both functionality and persistence, ensuring users can continue where they left off even after refreshing or reopening the browser.

The Clock section displays the current time in real time and gives users the option to switch between 12-hour and 24-hour formats based on their preference. The selected format is automatically saved to localStorage, allowing the app to remember user settings between sessions.

The Stopwatch section provides full timing controls, including play, pause, and reset functionality, along with support for recording multiple lap times. Users can track intervals efficiently while the application maintains stopwatch progress and lap history using localStorage. Even if the page is refreshed or reopened, the last stopwatch state and saved laps remain accessible, ensuring uninterrupted tracking and reliability.

The Alarm section enables users to create and manage multiple alarms for specific times throughout the day. Previously set alarms are also stored in localStorage, allowing users to retain their schedules without re-entering them after every session. By combining persistent storage with essential time-based utilities, the app delivers a seamless and practical productivity tool suitable for everyday use.
